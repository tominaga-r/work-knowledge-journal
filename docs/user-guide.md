# 操作ガイド

## 1. このアプリについて

業務知識を「ナレッジ」、日々の問い合わせ対応を「問い合わせメモ」として記録し、検索・関連付け・月次振り返りに活用するWindows向けアプリです。個人利用を主に想定しています。

**注意**：顧客氏名、連絡先、購入履歴、社外秘情報、非公開の商品情報などは登録しないでください。入力内容を自動的に機密判定する機能はありません。

## 2. 初めて使うとき

1. 配布されたWindows x64向けインストーラーからインストールします。配布前の段階では、GitHubのReleasesにファイルがない場合があります。
2. アプリを起動し、ナレッジ、問い合わせメモなどのメニューを確認します。
3. 必要に応じて、分類や共通タグを追加します。
4. まずは機密情報を含まないテスト用のメモで操作を試してください。

## 3. ナレッジを登録する

1. 「ナレッジを追加」またはナレッジ画面から新規作成へ進みます。
2. タイトル・本文・種類などを入力します。
3. 必要に応じて分類、共通タグ、情報元、お気に入りを設定します。
4. 内容を確認して保存します。
5. 一覧から登録した記録を選び、詳細確認・編集・削除を行います。

削除は元に戻せない場合があるため、確認画面の内容を読んでから実行してください。

## 4. 問い合わせメモを登録する

1. 「問い合わせメモを追加」から作成画面へ進みます。
2. タイトル、問い合わせ概要、対応メモ、次に活かすことなどを入力します。
3. 必要に応じて発生日、分類、情報元、タグ、お気に入りを設定します。
4. 保存後、詳細画面から関連するナレッジを紐付けます。

ナレッジと問い合わせメモを分けることで、業務知識と個々の対応履歴を整理できます。

## 5. 探す・振り返る

- **検索・絞り込み**：一覧でキーワード、分類、タグなどを指定して記録を探します。
- **お気に入り**：よく参照する記録をお気に入りに設定し、お気に入り画面からまとめて参照します。
- **月次振り返り**：対象月を選び、登録件数を参考に学び・課題・来月の目標などを入力します。必要に応じてMarkdown出力を利用します。

## 6. `.txt` / `.md` ファイルを取り込む

1. ナレッジまたは問い合わせメモの作成画面から取り込み操作を選びます。
2. `.txt` / `.md` を指定します。
3. ファイル内に複数の `##` 見出しがある場合は、複数の取り込み候補として分けられます。
4. 候補を選択し、タイトルと本文を確認・修正します。
5. 内容を確認して保存します。複数候補の場合は順番に登録する操作も利用できます。

ファイルを読み込んだだけでは、候補の内容が自動でDBへ保存されるわけではありません。

## 7. 通常バックアップを作成・復元する

**バックアップ作成**：設定のバックアップ画面から通常バックアップを作成・保存します。JSONには記録の本文を含み、暗号化されません。

**復元**：

1. **必要な現データを先にバックアップ**します。
2. 復元する通常バックアップファイルを選びます。
3. 形式検証の結果と、現在のデータ件数・バックアップ内の件数を確認します。
4. 対象が正しい場合に限り、アプリ画面の確認手順に沿って復元を実行します。
5. 復元後に記録が期待どおり表示されることを確認します。

復元は既存データを置き換える可能性があるため、テスト用データで操作を理解してから使用してください。

## 8. 暗号化バックアップを作成・復元する

暗号化バックアップではパスワードを設定して保存します。復元時には同じパスワードが必要です。**忘れたパスワードをアプリから復旧する機能はありません。**

- 暗号化されるのはバックアップファイルです。端末内SQLiteデータベースそのものではありません。
- パスワードを、バックアップと同じ場所に平文で保管しないでください。
- 誤パスワードや破損ファイルは復号・復元できません。

## 9. トラブル時の確認

| 状況                             | 確認すること                                                                      |
| -------------------------------- | --------------------------------------------------------------------------------- |
| 保存できない                     | タイトル・本文の必須項目や文字数、選択値を確認する                                |
| 取り込みできない                 | 拡張子が`.txt`または`.md`か、ファイルのサイズや内容の上限を超えていないか確認する |
| 復元ファイルを受け付けない       | このアプリで作成した種類のバックアップか、破損していないか確認する                |
| 暗号化バックアップを復号できない | パスワードとファイル内容を確認する。復号できなければ別の正常なバックアップが必要  |
| 記録が見当たらない               | 検索・分類・タグなどの絞り込み条件を解除して確認する                              |
