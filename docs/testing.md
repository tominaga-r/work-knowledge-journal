# テスト・検証方針

## 1. 基本方針

テスト件数やカバレッジの数値を増やすこと自体より、**入力境界、日付、テキスト取り込み、バックアップの形式検証、暗号化・復号**など、間違えると不具合が分かりにくい処理を優先する。

画面やSQLiteを利用した一連の操作は、自動単体テストとは別の手動確認で扱う。

## 2. 自動テスト

直近のローカル実行結果は**8ファイル・70テスト成功**。対象は次のとおり。

| 対象                     | 主な確認観点                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------- |
| 日付ユーティリティ       | ローカル日付・年月、月範囲とUTCの変換、異常値                                      |
| テキストユーティリティ   | 要約の整形・切り詰め、カンマ区切りの解析                                           |
| テキストファイル取り込み | `.txt` / `.md`、見出し分割、空内容、ファイル数・サイズ・文字数制限                 |
| ナレッジ入力スキーマ     | 必須入力、既定値、トリム、上限境界、タグ上限                                       |
| 問い合わせ入力スキーマ   | 必須入力、各フィールドの最大長、発生日の形式、タグ上限                             |
| 分類・タグ入力スキーマ   | 名称の上限、空文字、タグ名のカンマ禁止                                             |
| 暗号化バックアップ       | 暗号化→復号、誤パスワード、改ざん、ファイル形式・バージョン                        |
| 通常バックアップ検証     | 必須テーブル、形式不正、フィールド型、アプリ識別子、件数サマリー、未知テーブル警告 |

最新のテスト結果は実行時のCIまたは`npm run test`で確認する。

## 3. 静的チェック・監査

```bash
npm ci
npm run format:check
npm run lint
npm run test
npm run build
```

GitHub Actionsでは、これらのフロントエンド品質チェックをpush / Pull Requestで実行する構成としている。Windows向けNSISのビルドは、現段階ではローカルのTauri環境で別途確認する。

追加監査：

```bash
npm audit
npx knip
cd src-tauri
cargo audit
cargo check
```

`cargo audit` の指摘件数は`Cargo.lock`全体の結果なので、対象OSやfeature、修正可能性を調べたうえで判断する。

## 4. Windows配布版の手動検証

リリース候補のインストーラーで、次のチェック項目を順に確認する。

- [ ] NSISインストーラーでインストール・起動・終了・再起動できる
- [ ] ナレッジの作成・編集・削除と一覧表示ができる
- [ ] 問い合わせメモの作成・編集・削除と一覧表示ができる
- [ ] 検索・絞り込み・分類・タグの操作ができる
- [ ] 関連ナレッジの追加・解除・参照ができる
- [ ] お気に入りの追加・解除・一覧表示ができる
- [ ] 月次振り返りの保存・再表示とMarkdown出力ができる
- [ ] `.txt` / `.md` の取り込みを確認・修正してから保存できる
- [ ] 通常バックアップを作成し、テスト用データで復元できる
- [ ] 暗号化バックアップを作成・復号・復元できる
- [ ] 誤ったパスワードや不正ファイルはエラー表示になり、復元が始まらない
- [ ] アプリ再起動後もデータが保持される
- [ ] 幅の狭い画面でも主要な画面に移動できる

## 5. 未検証と今後の改善

- バックアップ復元の途中失敗・クラッシュ・電源断を含む統合テスト
- SQLite RepositoryのDB統合テストと画面のE2Eテスト
- 大量データ時の応答時間・メモリ使用量など定量的な性能測定
- インストーラーの署名・複数Windows環境での継続的回帰試験

この文書は**検証範囲を説明するためのもの**であり、製品の不具合ゼロや安全性の完全保証ではない。
